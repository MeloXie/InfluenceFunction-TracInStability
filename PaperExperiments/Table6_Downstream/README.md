# Table 6: Noisy-Label Detection and Downstream Pruning

## Purpose

This experiment reproduces **Table 6** in the paper, which evaluates the effectiveness of different influence estimation methods for:

- Noisy-label detection (AUPRC)
- Downstream data pruning and model retraining

The evaluation is conducted under several different data conditions, including:

- Dataset
- Density contrast
- Class imbalance

Each experimental setting is stored in an independent folder. Although the datasets differ, **all folders contain exactly the same notebook workflow and file structure**. Once users understand the workflow for one folder, the same procedure can be applied to all remaining settings.

# Reproducing the Experiment

Each experimental folder is reproduced independently using the following three stages.

## Stage 1 – Generate Noisy Training Data and Influence Scores

Open

```text
DownStreamExperiment.ipynb
```

Execute all notebook cells sequentially.

No code modifications are required.

The notebook generates the following intermediate files:

- `Clean_TestData.csv`
- `Noise_GroundTruth_and_TrainingLoss.csv`
- `NoisyLabel_TrainingData.csv`
- `NoisyLabel_FOIF_Scores.csv`
- `NoisyLabel_TracIn_Scores.csv`

These files are used in the subsequent stages.

---

## Stage 2 – Noisy-Label Detection

Open

```text
NoisyLabelEvaluation.ipynb
```

Execute all notebook cells sequentially.

The notebook automatically reads the files generated in Stage 1 and evaluates noisy-label detection performance.

The notebook reports:

- AUPRC
- Precision@10
- Recall@10
- Precision@20
- Recall@20
- Precision@30
- Recall@30

These results correspond to the noisy-label detection part of Table 6.

No parameter changes are required.

---

## Stage 3 – Downstream Pruning and Retraining

Open

```text
DownStreamExperiment-PruneAndRetrain.ipynb
```

This notebook evaluates downstream pruning performance by removing suspicious training samples and retraining the classifier.

### Step 1 – Select the Pruning Method

Modify

```python
method = ...
remove_fraction = ...
```

The available pruning methods are:

- `"No Pruning"`
- `"Random"`
- `"Training Loss"`
- `"FOIF"`
- `"TracIn"`

The pruning fraction can be selected as:

- `0.10`
- `0.20`
- `0.30`

For each combination of pruning method and pruning fraction, execute the notebook once.

---

### Step 2 – Record the Pruning Statistics

During execution, the notebook reports statistics such as

```text
Noisy samples among removed: ...
Noisy fraction among removed: ...
```

These values indicate how many noisy labels are successfully removed by the selected pruning strategy.

---

### Step 3 – Record the Retraining Accuracy

After pruning, the notebook automatically retrains the classifier.

The final test accuracy is displayed at the end of training.

This value corresponds to the downstream pruning performance reported in Table 6.

---

# Expected Output

Repeating Stage 3 for every combination of

- pruning method, and
- pruning fraction

produces:

- noisy-label detection results (AUPRC), and
- downstream pruning accuracy

which together reproduce the values reported in **Table 6**.

---

# Notes

- Every experimental folder follows exactly the same notebook workflow.
- The only difference between folders is the underlying dataset or data condition.
- Stage 1 only needs to be executed once for each experimental folder.
- Stage 2 only needs to be executed once after Stage 1.
- Stage 3 should be repeated for every combination of pruning method and pruning fraction required for the evaluation.
- The **Flip20-Diamonds** experiment performs influence estimation on the full Diamonds dataset (over **50,000 training samples**). Reproducing Stage 1 from scratch may therefore require a considerable amount of time.
- To simplify reproduction, the intermediate CSV files generated by Stage 1 are included in each folder. Users who only wish to reproduce the reported noisy-label detection and downstream pruning results may skip Stage 1 and directly execute `NoisyLabelEvaluation.ipynb` and `DownStreamExperiment-PruneAndRetrain.ipynb`.
